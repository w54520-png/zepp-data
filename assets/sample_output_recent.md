## 关键约定（LLM 解释时必须遵守）

1. **窗口**：`--days 7` 默认显示**过去 7 天**（含今天），按 `date >= today - 7天` 过滤
2. **HRV RMSSD** 是日均，不是单点；后缀 `[N 个采样]` 提示手表一天测了 N 次
3. **PAI 七天累计** 是 Zepp 官方指标（不是简单 sum of daily PAI），由 Zepp 算法算
4. **压力** 是首条曲线值（每日第一个采样），不是日均（如果要日均，用 `metric --metric stress`）
5. **特殊事件**区会列 `spo2_apnea_low` 等低血氧告警（仅呼吸暂停型手表才有，如 Amazfit Band 7）

## 常见误读

| 用户说 | 真实含义 |
|--------|---------|
| "最近 PAI 高不高" | 看 `PAI 七天累计`（周累计），不是 `PAI 当日` |
| "睡眠怎么样" | 用 `metric --metric sleep_score`，**不**在 recent 里 |
| "今天训练量大不大" | 看 `训练负荷当日`（sport_load_today），不是卡路里 |
| "我压力大" | 看 `压力（首日曲线值）` 趋势，多日 > 60 才算持续高压 |
